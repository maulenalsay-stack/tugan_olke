# Тіл таспа

«TikTok арқылы қазақ тілін үйрену: тәжірибелік зерттеу» ғылыми жобасының өнімі. Қазақ тілін күніне 20–30 минут қысқа роликтер арқылы үйренуге арналған сайт және телефон қосымшасы.

Орындаған: Мырзалы Олжас, №171 мектеп, Алматы, 2026. Жетекшісі: Солтанбекова Алия Алимбековна.

## Сайтты іске қосу (GitHub Pages)

1. Репозиторийде **Settings → Pages** бетін аш.
2. **Source**: `Deploy from a branch`, **Branch**: `main`, папка: `/ (root)`. **Save** бас.
3. 1–2 минуттан кейін сайт мына мекенжайда ашылады:
   `https://maulenalsay-stack.github.io/tugan_olke/til-taspa/`

Осыдан кейін `main` тармағындағы кез келген өзгеріс сайтқа автоматты түрде шығады.

## Мазмұнды өзгерту

Барлық фразалар бір файлда: [`data/cards.json`](data/cards.json). GitHub-та файлды ашып, қарындаш (Edit) белгішесін бас, түзет, **Commit changes** бас.

Бір фразаның құрылымы:

```json
{
  "id": "08-1",
  "d": 8,
  "cat": "maqal",
  "kk": "Бірлік бар жерде — тірлік бар.",
  "ru": "Где единство — там и жизнь.",
  "note": "Ұйқас: бірлік — тірлік.",
  "q": "Мақалдың негізгі ойы:",
  "o": ["Бірлік — өмірдің негізі", "Жалғыз жүрген жақсы", "Жұмыс керек емес"],
  "mk": ["Бірлік", "тірлік"],
  "all": false,
  "wrong": null,
  "nosub": false
}
```

| Өріс | Мағынасы |
| --- | --- |
| `id` | Файл аты, аудио осы атпен ізделеді (`08-1.m4a`) |
| `d` | Күн нөмірі, 1–28 |
| `cat` | Түрі: `maqal`, `sozdik`, `gram`, `dialog`, `aitylym`, `tyndalym`, `sauat`, `tusindir` |
| `kk` | Қазақша мәтін. Жаңа жол — `\n` |
| `ru` | Орысша субтитр |
| `note` | «Аңғар» кеңесі |
| `q`, `o` | Сұрақ және 3 жауап. **Бірінші жауап әрқашан дұрыс**, сайт оларды өзі араластырады |
| `mk` | Сары түспен белгіленетін сөз соңдары немесе сөздер |
| `all` | `true` болса, `mk` ішіндегі әріптер барлық жерде белгіленеді (айтылым роликтері үшін) |
| `wrong` | Сауат роликтерінде қате жазылған нұсқа, мысалы `"каксын?"` |
| `nosub` | `true` болса, субтитр алдымен жабық тұрады (тыңдалым) |

## Аудио қосу

Оқушының жазбасын `audio/` папкасына жүкте: **Add file → Upload files**. Файл аты = фразаның `id`-і:

- роликтер: `08-1.m4a`, `08-2.m4a` … (`.m4a` немесе `.mp3`)
- дуэт: `cafe-1.m4a` … `cafe-6`, `school-1` … `school-6`, `phone-1` … `phone-6`
- тест: `test-1.m4a` … `test-6.m4a`

Жазба табылса, сайт соны ойнатады және роликке «Оқушы дауысы» белгісін қояды. Табылмаса, `audio/tts/` папкасындағы компьютер дауысы ойнайды.

Жазу тізімі: [Til-taspa-dybys-tizimi.pdf](Til-taspa-dybys-tizimi.pdf).

## Телефонға орнату

- **Android (Chrome):** сайтты аш → «Телефонға орнату» картасындағы **Орнату** батырмасын бас. Немесе мәзір (⋮) → «Қосымшаны орнату».
- **iPhone (Safari):** «Бөлісу» батырмасы → «На экран Домой / Add to Home Screen».

Орнатылған соң Тіл таспа басты экранда жеке қосымша болып ашылады. Бір рет ашылған беттер интернетсіз де жұмыс істейді. Аудионы тыңдау үшін интернет керек.

### Play Market-ке APK жасау (қаласаң)

1. [pwabuilder.com](https://www.pwabuilder.com) сайтына GitHub Pages мекенжайын енгіз.
2. **Package for stores → Android** таңда, APK/AAB файлын жүктеп ал.
3. Телефонға тікелей орнатуға немесе Google Play Console арқылы жариялауға болады.

## Файлдар

| Файл | Не үшін |
| --- | --- |
| `index.html` | Сайттың өзі (дизайн және код) |
| `data/cards.json` | 28 күннің 112 фразасы |
| `audio/` | Оқушының жазбалары |
| `audio/tts/` | Компьютер дауысы (MMS), жазба жоқ кезде ойнайды |
| `manifest.webmanifest`, `sw.js`, `icons/` | Телефон қосымшасы үшін |

Прогресс (күнделік, тест, сөздік) әр оқушының өз браузерінде сақталады.
